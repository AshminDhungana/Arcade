### AC-12 — License activation gate (offline Ed25519 + HWID)
**Status: ✅ VERIFIED**

**Evidence:**
- `LicensingService.verify_license()` (`backend/licensing/service.py`):
  - Loads `license.key` (Ed25519 signed payload)
  - Verifies signature against embedded public key
  - Computes HWID: `py-machineid` primary + MAC/hostname fallback → SHA256
  - Compares HWID in license vs current machine
- Launcher (`launcher.py`): On startup → `LicensingService.verify_license()` → pass = proceed to wizard/server; fail = show activation screen
- Activation screen: Enter license key → validates signature + HWID match → writes `license.key` + `arcade.config.json`
- Tested: Valid license on licensed machine = pass; Same license on different machine = fail (HWID mismatch); Corrupted license = fail (signature invalid); Missing license = activation screen
- No network calls during verification — fully offline
- Keygen: `tools/keygen/generate_license.py` (internal only, not shipped)

**Checklist:** [x] Ed25519 verify [x] HWID match [x] Offline [x] Activation UI [x] Failure modes tested

### AC-13 — Kiosk overlay blocks desktop on Win/macOS/Linux
**Status: ⚠️ DEFERRED (Partial)**

**Evidence:**
- **Windows:** ✅ Verified — `kiosk: true`, `alwaysOnTop: true`, `closable: false`, global shortcuts blocked (Alt+F4, F12, Ctrl+P, Ctrl+Shift+I, Alt+Shift+I). Known gap: Ctrl+Alt+Del cannot be blocked (OS-level).
- **Linux (X11):** ✅ Verified — `kiosk: true` works; shortcuts blocked via `before-input-event`.
- **Linux (Wayland):** ⚠️ **DEFERRED** — `setAlwaysOnTop(true, 'screen-saver')` is non-functional on Wayland (Electron upstream limitation). Fallback: maximized window + `alwaysOnTop` but NOT bypass-proof. Requires dedicated kiosk compositor (Cage, gnome-kiosk, ubuntu-frame) for true lockdown. Documented in `docs/agent-setup.md` as deployment requirement.
- **macOS:** ⚠️ **DEFERRED** — Implementation exists in git history (commit `54256ca`) but **not merged to main**. Current `main` branch only has `windows.ts` and `linux.ts`. macOS platform service (`macos.ts`) needs to be restored from orphaned commits and tested on real hardware. Known gaps: Cmd+Tab cannot be blocked by Electron; Cmd+Q/W/H/M blocked via `globalShortcut` + `Menu.setApplicationMenu(null)`.

**Deferred Items:**
| Platform | Status | Blocker | Target |
|----------|--------|---------|--------|
| macOS | Code exists (orphaned commits) | Not on `main`; needs real Mac testing | Phase 7.1 (post-launch patch) |
| Linux Wayland | Documented limitation | Electron API gap | Deploy with X11 or kiosk compositor |

**Checklist:** [x] Windows ✅ [x] Linux X11 ✅ [ ] Linux Wayland (doc'd gap) [ ] macOS (code exists, not merged)

### AC-19 — Lifespan context manager (no @app.on_event)
**Status: ✅ VERIFIED**

**Evidence:**
- `backend/main.py` uses `@asynccontextmanager` lifespan:
  ```python
  @asynccontextmanager
  async def lifespan(app: FastAPI):
      # Startup: DB init, Alembic migrate, APScheduler, WSManager
      yield
      # Shutdown: Scheduler shutdown, WSManager close, DB pool dispose
  app = FastAPI(lifespan=lifespan)
  ```
- No `@app.on_event("startup")` or `@app.on_event("shutdown")` in codebase (verified by `grep -r "@app.on_event" backend/`)
- Logs show clean startup/shutdown sequence without deprecation warnings
- Tested: `uvicorn backend.main:app --reload` → Ctrl+C → clean exit

**Checklist:** [x] Lifespan used [x] No deprecated decorators [x] Clean startup/shutdown logs
